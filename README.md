Учёт заявок на печать

Десктопное приложение для учёта заявок на печать с автоматическим расчётом стоимости.

Запуск
1. Python 3.10+
2. Запустите: "python app.py"

Функции
- Добавление заявок
- Поиск по имени или описанию
- Смена статуса (в очереди -> печатается -> готово)
- Удаление заявок
- Автоматический расчёт стоимости
- Сводка продаж за день
